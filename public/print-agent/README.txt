[ENGLISH GUIDE]
--------------------------------------------------------------------------------
This agent links your Cyber Cafe / Jan Seva Kendra / Xerox Shop computer with 
your online QR Print Seva portal (https://qrprintseva.vercel.app).

FEATURES:
1. Auto-detects all installed physical printers (HP, Canon, Epson, Brother, TVS).
2. Supports 5 dedicated printer slots (B&W, Color, Duplex, A3, Photo 4x6).
3. Auto-prints customer jobs silently in the background upon UPI payment.
4. "Ding!" audio chime on every incoming job.
5. Zero-Storage Security (Files auto-deleted from disk immediately after printing).
6. Counter Approval switch: enable if you want to inspect jobs before printing.

HOW TO RUN:
Option 1: Instant Python Launch
  - Double click `run_agent.bat` (Requires Python 3.8+)
  - Enter your Shop ID (e.g., DEMO_FE8F53D1) found in your web dashboard.
  - Click "Save & Sync Settings". The agent status will turn green!

Option 2: Build Standalone .EXE (Single file without Python)
  - Double click `build_exe.bat`.
  - Your compiled standalone `QR-Print-Seva-Agent.exe` will appear in the `dist` folder.
